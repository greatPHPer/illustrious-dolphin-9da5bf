The VSIX "VS Editor Plus", please download it from this marketplace page

Comment/Uncomment

Comment/uncomment buttons appear on every line that is visible in the scroll pane for all .cs and .js files

When the scrolling occurs, the buttons are removed from the page. The buttond are only in the buffer and not in the entire text area.

Import missing tables from other databases at runtime

The databases which has the missing table will be listed and on clicking OK button, the table is copied from the existing database.

Clear all functions with at least one error

The methods with atleast one errors will be removed when OK is clicked.

Clear all empty functions

The methods which are empty will be removed when OK is clicked.
