Visual Studio for Beginners

Visual Studio is an IDE that helps you write, run, debug, test, and manage applications.

Create a project

Choose Create a new project, select a template such as Console App, choose a modern .NET version, and create the project.

Run your application

Use the Start button or Ctrl+F5 to run without debugging. Use F5 when you want the debugger attached.

Set a breakpoint

Click beside a source-code line to create a breakpoint. Start debugging and Visual Studio will pause when execution reaches that line.

Inspect values

While paused, use Locals, Watch, and hover information to inspect variables and understand what the program is doing.
