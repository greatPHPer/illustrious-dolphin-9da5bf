C# Methods for Beginners

A method is a named block of code that performs a task. Methods make programs easier to read, test, and reuse.

A simple method

static void SayHello()
{
    Console.WriteLine("Hello!");
}

SayHello();

Parameters

static void Greet(string name)
{
    Console.WriteLine($"Hello, {name}!");
}

Greet("Ravi");

Return values

static int Add(int a, int b)
{
    return a + b;
}

int result = Add(10, 20);

Start with small methods that do one clear job. Later, methods become the building blocks of classes and larger applications.
