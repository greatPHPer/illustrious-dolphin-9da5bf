SQL SELECT, WHERE, and ORDER BY for Beginners

SQL lets you retrieve and work with data stored in relational databases.

SELECT

SELECT Name, Department
FROM Employees;

This returns the selected columns from the Employees table.

WHERE

SELECT Name, Department
FROM Employees
WHERE Department = 'IT';

WHERE filters rows so you only get records matching a condition.

ORDER BY

SELECT Name, Salary
FROM Employees
ORDER BY Salary DESC;

DESC sorts from high to low; ASC sorts from low to high.

Learning path
