What Is .NET? A Beginner's Guide

.NET is Microsoft's development platform for building web, desktop, cloud, mobile, and other applications. C# is one of the main languages used with it.

.NET runtime

The runtime provides the environment that runs managed .NET applications.

.NET SDK

The SDK provides commands and tools for creating, building, testing, and publishing applications.

dotnet --info
dotnet new console
dotnet build
dotnet run

What is a project?

A project contains source code, configuration, dependencies, and build information. A solution can contain multiple related projects.

What is NuGet?

NuGet is the package ecosystem used to add reusable libraries to .NET applications.
