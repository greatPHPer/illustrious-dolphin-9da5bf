C# if, else, and Loops: A Beginner's Guide

Programs often need to choose what to do or repeat an operation.

if and else

int age = 20;
if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Minor");
}

for loop

for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}

foreach

string[] names = { "Asha", "Ravi", "Meena" };
foreach (var name in names)
{
    Console.WriteLine(name);
}

Use conditions for decisions and loops when the same operation needs to happen repeatedly.
