JWT Decoder / Inspector

Decode a JSON Web Token's header and payload for development and troubleshooting. The token stays in your browser.

Important: decoding is not verification. This tool does not verify signatures, issuer, expiry, or trustworthiness. Never paste sensitive production tokens into a public tool.
