C# Hello World: Your First Program

If you are completely new to C#, the best starting point is a tiny program you can run and change yourself.

1. Create a console project

In Visual Studio, create a new Console App using modern .NET. You can also create one from a terminal with dotnet new console.

2. Write the program

Console.WriteLine("Hello, World!");

Console.WriteLine writes text to the console window. The text between quotes is a string.

3. Run it

Run the project from Visual Studio or use dotnet run. You should see Hello, World!.

4. Experiment

Console.WriteLine("Welcome to C#");
Console.WriteLine(2 + 3);

Changing small pieces of working code is one of the fastest ways to learn programming.
