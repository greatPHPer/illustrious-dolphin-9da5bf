ASP.NET Core for Beginners: Build Your First Web Application

ASP.NET Core is the web framework in .NET for building websites, web APIs, real-time applications, and backend services.

Create a project

In Visual Studio choose an ASP.NET Core template, or use the .NET CLI to create one from a terminal.

dotnet new webapp -n MyFirstWebApp
cd MyFirstWebApp
dotnet run

What happens?

The application starts a web server and listens on a local HTTP or HTTPS address. Open the displayed address in your browser.

Pages, controllers, and APIs

ASP.NET Core supports several application styles. Razor Pages are useful for page-focused applications, MVC uses controllers and views, and Web API controllers or minimal APIs are commonly used for HTTP APIs.
