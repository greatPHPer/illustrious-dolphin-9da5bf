Developer Tools

Small, practical utilities for everyday development work. These tools run in your browser, so normal input is processed locally and is not uploaded by Algolassi.

Security: never paste production passwords, private keys, access tokens, API secrets, or confidential customer data into online tools.

{ }

JSON Formatter & Validator

Pretty-print JSON and get a useful syntax error when the input is invalid.

64

Base64 Encoder / Decoder

Encode or decode UTF-8 text without sending it to a server.

ID

GUID Generator

Generate one or several RFC 4122-style UUIDs using the browser crypto API.

JWT

JWT Inspector

Decode a JWT header and payload for debugging. Signature verification is not performed.

.*

Regex Tester

Test JavaScript regular expressions and inspect the matches.

TS

Unix Timestamp

Convert Unix seconds or milliseconds to a readable date and back.

URL

URL Encoder / Decoder

Safely encode or decode complete URLs, query values, or text.

<>

HTML Encoder / Decoder

Escape HTML-sensitive characters or decode HTML entities.
