C# Variables and Data Types for Beginners

Variables let a program store values so it can use them later.

Common types

string name = "Dhilip";
int age = 31;
double price = 99.50;
bool isActive = true;

string stores text, int stores whole numbers, double stores decimal values, and bool stores true or false.

var

var city = "Chennai";
var count = 10;

C# infers the type from the value. var does not mean the variable has no type.

Changing values

int score = 10;
score = 20;

A variable can receive another value compatible with its type.
